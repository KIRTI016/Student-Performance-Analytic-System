# Student Performance Analytics System

## 1. Project Title
Student Performance Analytics System

## 2. Objective
Build a Python-based Student Performance Analytics System that reads student data, processes and analyzes it using NumPy and Pandas, and produces meaningful results such as marks summary, averages, grades, pass/fail statistics, subject-wise performance, and top performers.

## 3. Technologies Used
- Python
- NumPy
- Pandas

## 4. Dataset Description
The dataset contains student records with the following information:
- Student ID
- Name
- Department
- Python marks
- DBMS marks
- DSA marks
- OS marks
- JavaScript marks
- Attendance

The dataset contains 15 student records.

## 5. Implementation
- Student data is stored in a CSV file.
- Pandas is used to read and organize the data.
- NumPy is used for numerical calculations.
- Functions are used for grade calculation.
- Loops are used to process student records.
- Total and average marks are calculated.
- Grades and pass/fail results are generated.
- Subject-wise performance is analyzed.
- Highest, lowest and class average performance are calculated.
- The top-performing student is identified.

## 6. Key Features
- Student data analysis
- Total marks calculation
- Average marks calculation
- Grade calculation
- Pass/Fail identification
- Subject-wise average
- Highest and lowest performance
- Class average
- Top performer identification
